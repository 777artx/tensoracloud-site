What Tensora is

Tensora gives AI software one place to access models, GPU compute, APIs, MCPs, and payments.

Instead of managing separate providers, accounts, and billing systems, software connects to Tensora and uses what it needs from one account.

The Tensora app is where you create API keys, fund usage, and track requests, payments, and infrastructure activity.

Get an API key

  1. Sign in with Google or a wallet.
  2. Open API Access.
  3. Create a key for your project and copy the secret once.
  4. Send it as a Bearer token with API requests.

One Tensora API key gives your software access to supported services. Your project balance pays for usage.

Auth and funding

Home, Models, Compute, Tools, and Docs are available without an account. API Access, Activity, Billing, and Dashboard require a signed-in session.

Fund your balance with supported stablecoins or other available payment methods. Open Billing to add funds and track spend.

Call models

Use tensora/auto to let Tensora choose a model based on speed, cost, or quality. You can also select a specific model from the catalog.

Supported model requests use an OpenAI-compatible chat format.

curl https://api.tensora.cloud/v1/chat/completions \
  -H "Authorization: Bearer $TENSORA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "tensora/auto",
    "messages": [{ "role": "user", "content": "Hello" }]
  }'

Compute and tools

Compute lets you compare GPU pricing and availability across infrastructure providers.

Offers with direct Tensora support can be purchased through Tensora. Other offers take you directly to the provider.

Tools lets you discover and connect supported APIs and MCPs to your project.

Activity and billing

Activity shows what your software has done through Tensora, including model requests, compute activity, tool usage, payments, timestamps, and status.

Billing shows your balance, deposits, infrastructure spend, and payment activity. Dashboard summarizes usage across your account.

Networks

Supported stablecoins can be used to fund Tensora usage. When a payment settles onchain, Tensora shows the transaction and explorer link when available.
